# jhasanjiv5.github.io

Source of [jhasanjiv5.github.io](https://jhasanjiv5.github.io): a single static page (`index.html`, no build step, no theme).
Its look matches the [GitHub profile README](https://github.com/jhasanjiv5/jhasanjiv5): Apple system fonts and colours, light and dark mode.

- Edit `index.html` and push to `main`; GitHub Pages serves it as is (`.nojekyll`).
- `assets/image/career-map*.svg` are drawn by `python3 build_map.py` (edit the stops there).
